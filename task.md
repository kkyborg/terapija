# TASK:
Create a command line application in Swift programming languge whose purpose is to make a daily schedule for taking medicines.

# INPUT:
The list of medicines, including quantities, dosages, rules, excemptions and special notes (special cases). All of these should be taken into account when creating a daily schedule.

The list of medicines can be found in "listaLekova.md" file. Use that as input to construct the data structrues that will be later used for other inputs.

# OUTPUT:
Output should be the proposed daily schedule when the patient should take which medicine. The following daily events should be also taken into account when creating the daily schedule:

- Wake up time
- Breakfast
- Launch
- Dinner
- Sleep time
